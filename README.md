# Молниезащита для AutoCAD

Плагин для AutoCAD 2024–2027. Рассчитывает зоны защиты стержневых молниеприёмников по
**РД 34.21.122-87** или **СО 153-34.21.122-2003**, подбирает высоту мачт и рисует:

- **план** — границы зон на высотах hx1, hx2… с выносками (высота, уровень защиты, rx, rcx), молниеприёмники Мл1…Млn с выносками, размеры между молниеприёмниками и до осей свечей и клапанов;
- **вид сбоку** — профиль зоны для каждого уровня защиты, здание жирным контуром с выноской габаритов, размеры h, H, hx1…, rx1… и цепочка размеров по горизонтали; масштаб вида может отличаться от плана;
- **таблицы расчёта** — объекты, одиночные молниеприёмники (h, h0, r0, rx), пары (L, hc, rc, rcx);
- **описательную часть** по редактируемому шаблону.

Работает офлайн, без ИИ и сетевых сервисов.

## Установка

1. Скачайте `LightningProtection-Setup-<версия>.exe` из раздела **Releases** репозитория.
2. Закройте AutoCAD и запустите установщик. Права администратора не нужны: плагин ставится в
   `%APPDATA%\Autodesk\ApplicationPlugins` текущего пользователя.
3. Запустите AutoCAD — на ленте появится вкладка **«Молниезащита»**.

Установщик показывает инструкцию и оставляет её в меню «Пуск» → «Молниезащита для AutoCAD» → «Инструкция»
(текст — [installer/USER_GUIDE.txt](installer/USER_GUIDE.txt)). Удаление — там же или через «Параметры Windows» →
«Приложения».

Если антивирус блокирует установщик (неподписанный exe может попасть под эвристику, например
`Trojan:Win32/Sabsik.FL.A!ml`), скачайте из релиза архив `LightningProtection-<версия>.zip` и скопируйте папку
`LightningProtection.bundle` в `%APPDATA%\Autodesk\ApplicationPlugins` — см.
[installer/MANUAL_INSTALL.txt](installer/MANUAL_INSTALL.txt).

## Сборка

Нужны .NET SDK 10 и, для установщика, [Inno Setup 6](https://jrsoftware.org/isinfo.php)
(`winget install JRSoftware.InnoSetup`).

```powershell
.\build-bundle.ps1 -Installer -Zip   # пакет dist\LightningProtection.bundle, установщик и архив для ручной установки
.\build-bundle.ps1 -Install          # пакет и сразу установка в ApplicationPlugins (для разработки)
```

Для релиза сначала закоммитьте изменения, потом собирайте: .NET SDK вшивает хэш текущего коммита в версию
сборки (`0.2.0+<коммит>`).

Скрипт собирает три версии (`net48` для 2024, `net8.0-windows` для 2025–2026, `net10.0-windows` для 2027).
Версия берётся из `Directory.Build.props`. Для разовой проверки можно сделать `NETLOAD` нужной DLL из `dist`.
Если AutoCAD держит `dist` открытым, соберите в другую папку: `-OutDir dist-new`.

Текст, таблицы, выноски и размеры выполняются наклонным шрифтом **GOST Common Italic** (стиль `МЗ_GOST`,
размерный стиль `МЗ_Размеры` с засечками). Прямой `GOST Common.ttf` не подходит: в нём на местах «, » и ±
нарисованы ¼ и ½. Скрипт сборки кладёт оба файла шрифта в `Contents\Fonts` пакета (из папки `fonts` репозитория
или из шрифтов Windows), а плагин устанавливает их пользователю без прав администратора, если шрифта нет.
Проверьте, что лицензия шрифта разрешает его распространение.

## Команды

| Команда | Что делает |
|---|---|
| `LPROT` | Окно исходных данных: объекты, молниеприёмники, расчёт, подбор высоты, отрисовка |
| `LPROTDRAW` | Перерисовать всё по данным, сохранённым в чертеже |
| `LPROTREPORT` | Протокол расчёта в командную строку |
| `LPROTCLEAR` | Удалить всё, что нарисовал плагин |

## Порядок работы

1. `LPROT` → выбрать норму и Td (ч/год). Проверить «единиц в 1 м» (1000 — чертёж в мм) и масштабы.
   Чертёж ведётся в натуральную величину; «Масштаб плана 1:» задаёт масштаб печати, под который увеличиваются
   текст, выноски и размеры. 0 или 1 — масштаб подбирается по размерам плана. «Вид сбоку 1:» — свой масштаб
   вида сбоку (0 — как план): геометрия вида увеличивается в Mплана / Mвида раз, размеры показывают натуральные значения.
2. **Расчётный участок** — для каждого отдельно стоящего здания со своей молниезащитой заведите участок
   (**+ Новый участок**). Участки считаются независимо: у каждого свои объекты, молниеприёмники, подбор высоты,
   вид сбоку, таблицы, описание и нумерация hx. Объекты и мачты можно переносить между участками.
3. **+ Здание** — выбрать замкнутую полилинию, ввести отметку верха.
4. **+ Продувочная свеча ГРУ** / **+ Дыхательный клапан** — указать ось и отметку обреза.
   По умолчанию: свеча — зона Б, цилиндр 5 × R 5 м (для прямой трубы — «Полусфера» R 5 м);
   клапан — зона А, цилиндр 2,5 × R 5 м. Значения редактируются в таблице.
5. **+ Указать на чертеже** — расставить молниеприёмники Мл1, Мл2… (нумерация сквозная по чертежу).
6. **Подобрать высоту** — минимальная общая высота мачт участка (без отметки «Фикс.»), при которой защищены все его объекты.
7. **Отрисовать участок** / **Отрисовать все участки** — при первой отрисовке участка вид сбоку, таблицы и описание
   ставятся одним «листом» (таблицы слева вверху, описание справа, вид сбоку ниже) с предпросмотром под курсором,
   рамкой габаритов и размером в мм на листе; ключ «Отдельно» — по одной части. Масштаб плана общий для чертежа.

Данные проекта хранятся в словаре чертежа (`LPROT_PROJECT`). Отрисованные объекты помечены XData `LPROT` с кодом
участка: перерисовка участка заменяет только его объекты. Чертежи прежних версий открываются как один «Участок 1».

## Расчётная модель

- Одиночный молниеприёмник — конус (h0, r0), rx = r0 (h0 − hx) / h0.
  РД-87 прил. 3: зона А h0 = 0,85h, r0 = (1,1 − 0,002h)h; зона Б h0 = 0,92h, r0 = 1,5h.
  СО 153 табл. 3.4 — по надёжности 0,9 / 0,99 / 0,999 и диапазонам высот до 150 м.
- Двойной: hc по РД-87 (L ≤ h, h < L ≤ 2h для А, h < L ≤ 6h для Б) или по СО 153 табл. 3.6 (Lmax, Lc),
  rcx = rc (hc − hx) / hc. Для разной высоты hc и rc — средние. Выше hc — выступы lx (СО 153, ф. 3.5).
- Многократный: объединение зон всех пар и треугольников внутри троек попарно связанных стержней.
- Проверка — объект в плане (контур здания или круг пространства) целиком внутри сечения зоны на своей hx.
- Ожидаемое число поражений N = [(S + 6h)(L + 6h) − 7,7h²]·n·10⁻⁶, n — по табл. 2 РД-87 или 6,7·Td/100 (СО 153).

## Что проверить проектировщику

- Категорию, тип зоны и надёжность для каждого объекта — по табл. 1 РД-87 / разд. 2 СО 153. Значения по умолчанию в `ObjectPresets` — только отправная точка.
- Размеры защищаемого пространства над обрезом свечи — по давлению газа и случаю выброса (РД-87).
- Для объектов, требующих отдельно стоящих молниеприёмников, — расстояния по воздуху и земле (пока не проверяются).

## Структура

```
src/LightningProtection.Core   расчёт (netstandard2.0): нормы, геометрия зон (NetTopologySuite), подбор, отчёт
src/LightningProtection.Acad   плагин AutoCAD: команды, окно WPF, отрисовка
tests/                         модульные тесты ядра (xUnit)
templates/description.txt      шаблон описательной части
bundle/PackageContents.xml     манифест автозагрузки
installer/                     установщик Inno Setup, инструкция пользователя и инструкция по ручной установке
```

Тесты: `dotnet test tests/LightningProtection.Core.Tests`.
